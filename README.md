# PeregrineOS

### Take flight and make it yours.

PeregrineOS is a lightweight, Arch Linux-based distribution designed to give you a clean starting point and the freedom to build a system that feels like your own.

Choose the applications, tools, and desktop environment that suit you. Whether you prefer a minimal setup or a fully customized desktop, PeregrineOS gives you the space to make it yours.

## Getting started

Boot the live ISO and follow the on-screen guide to connect to the internet and install your system with `archinstall`. After installation, choose the software and desktop environment you want.
