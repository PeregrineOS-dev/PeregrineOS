# PeregrineOS

### Take flight and make it yours.

PeregrineOS is a lightweight, Arch Linux-based distribution built to give you a clean starting point and the freedom to shape your system your way. It is designed for people who want to choose their own applications, tools, and desktop environment instead of starting with a preloaded collection of software.

Whether you prefer a minimal system or a customized desktop, PeregrineOS gives you the flexibility to build an environment that fits your needs.

## Getting started

1. Boot the PeregrineOS live ISO.
2. Connect to the internet. For wireless connections, you can use `iwctl`.
3. Read the getting-started guide by running:

   ```bash
   peregrine-tutorial
   ```

4. Start the guided installation with:

   ```bash
   archinstall
   ```

5. After installation, choose the applications and desktop environment you want for your system.

## Helpful commands

### `peregrine-tutorial`

Displays the getting-started guide, with information about booting PeregrineOS, connecting to the internet, installing the system, and choosing software.

```bash
peregrine-tutorial
```

### `peregrine-setup`

Opens a menu of software profiles to help you choose what to install. Options include a minimal setup, desktop environments such as KDE Plasma, GNOME, Xfce, and Cinnamon, and collections of development, system, and file or terminal tools.

```bash
peregrine-setup
```

Review the options before installing software, and choose only the profiles that suit your needs.

## Project goals

- Provide a lightweight starting point.
- Let users choose their own software and desktop environment.
- Offer clear guidance for first-time installation.
- Use Arch Linux and `archiso` as the foundation.

## Platform

- **Architecture:** x86_64
- **Base:** Arch Linux
- **ISO creation:** `archiso`
